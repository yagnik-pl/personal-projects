# Indian Art Raga Workbench — Carnatic Music

This folder works with the precomputed feature dataset:

`../Indian Art Music Raga Recognition Dataset (features)/RagaDataset`

The trainer flattens pitch, tonic, nyas-segment, and tani-segment feature files
into a tabular CSV, then trains several classical models:

- k-nearest neighbors
- RBF SVM
- Gaussian Naive Bayes
- Random Forest
- Extra Trees
- HistGradientBoosting
- soft voting ensemble

Run:

```powershell
..\.venv\Scripts\python.exe train_indian_art_raga.py
```

Outputs are written to `outputs/`:

- `indian_art_carnatic_features.csv`
- `indian_art_carnatic_skipped_rows.csv`
- `indian_art_carnatic_model.joblib`
- `indian_art_carnatic_metrics.json`

EDA plots are written to `plots/` (generated by `eda_plots.py`).

The default split groups by `artist` to reduce leakage from artist-specific
recording and performance style.
